# Form font

Derived from Google Fonts Noto Sans SC, licensed under the accompanying SIL Open Font License.
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

The variable font was instantiated at weight 400 with fontTools. GSUB, GPOS, GDEF and BASE shaping tables were removed for predictable direct Latin, numeric and Chinese glyph mapping in pdf-lib/fontkit. Embed the complete font: subsetting can omit visible glyph outlines.
